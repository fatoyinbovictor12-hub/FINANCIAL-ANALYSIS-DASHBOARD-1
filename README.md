# Retail Sales Performance Dashboard

A dynamic Excel dashboard analyzing monthly sales performance across regions, products, and sales teams for the Retail Division. This interactive tool is designed to help stakeholders track key revenue metrics, evaluate regional growth, and optimize inventory distribution.

![Sales Performance Dashboard](your-image-filename.png)

## 🎯 Project Objective
The goal of this project is to consolidate fragmented retail sales data into a single source of truth. It provides the leadership team with actionable insights into revenue trends, regional performance, and product category health.

## 💡 Key Metrics & Insights
Based on the current reporting period:
*   **Total Revenue:** Generated **32,040,000 NGN** across all operating channels.
*   **Volume Sold:** Successfully moved **227 units** with an **Average Sale** value of **1,780,000 NGN**.
*   **Top Performer:** **Phone** dominates the retail mix as the top-grossing product, accounting for **41%** of overall product contribution.
*   **Regional Dominance:** **Lagos** leads regional sales performance, followed closely by **Abuja** and **Port Harcourt**.
*   **Seasonal Trends:** Monthly sales experienced a sharp upward spike in **April**, stabilizing through May and June.

## 🛠️ Features & Tools Used
*   **Data Visualization:** Custom line, bar, and doughnut charts tailored to retail KPIs.
*   **Interactive Slicers:** Dynamic filtering capabilities allowing users to segment data by **Region**, **Product**, and **Salesperson** instantly.
*   **KPI Cards:** High-level summaries tracking Total Sales, Quantity Sold, Average Sale, and Top Product.

## 📂 How to Use
1. Download the `Sales Performance Dashboard.xlsx` file from this repository.
2. Open the file in Microsoft Excel (Enable Macros/Content if prompted).
3. Use the interactive filter "pills" on the top left to slice the data by your preferred metrics.
